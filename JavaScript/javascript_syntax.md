# JavaScript Syntax


### Terminal operations

- Use **node** to run single javascript files in the terminal. Ex. *node intro_to_classes.ts*



### Syntax Operations

#### For Loop
```javascript
//For loop structure for looping through an array:
const fruits = ["apple", "banana", "cherry"];
for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}

```

### .map()
Used for arrays to go through the array one item at a time. Shape:
```javascript
const newArray = oldArray.map(item => whatToReturn)

```
